# BrickSetu Agent Guidance

Read `AGENTS.md` first. It provides the repository-wide architecture rules. Then use the focused guidance that matches the work being performed:

| File | Use when working on |
| --- | --- |
| `implementation-playbook.md` | Any new or changed business feature. |
| `frontend.md` | React routes, UI, client data, and responsive behavior. |
| `backend.md` | Node.js, Fastify, REST endpoints, services, and authorization. |
| `database.md` | PostgreSQL schemas, migrations, PL/pgSQL, stock, or finance integrity. |

The project documentation in `docs/` is authoritative for technology and domain decisions. If this guidance conflicts with a current user request, follow the user request and update the relevant documentation as part of the work.
